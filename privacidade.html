Vero Signare — WebPKI

Extensão de Assinatura Digital A3 ICP-Brasil

Política de Privacidade

Sem coleta de dados

Esta Política de Privacidade descreve como a extensão Vero Signare — WebPKI trata (ou melhor: não trata) dados dos seus usuários.

Dados coletados

A extensão não coleta, não armazena e não transmite nenhum dado pessoal ou informação de uso. Não há telemetria, analytics, cookies ou qualquer forma de rastreamento implementada.

Como a extensão funciona

O único propósito da extensão é servir como ponte segura entre uma página web e o host nativo instalado no computador do usuário. O fluxo completo ocorre localmente:

  • A página web envia o hash do documento a ser assinado;
  • A extensão repassa esse hash ao host nativo via Native Messaging;
  • O host nativo solicita o PIN ao usuário e acessa o token A3 via PKCS#11;
  • Apenas a assinatura digital gerada é retornada à página web.

A chave privada do certificado jamais sai do dispositivo físico (token USB ou smartcard) e nenhuma informação é enviada a servidores externos.

Permissões utilizadas

  • nativeMessaging — exclusivamente para comunicação com o host nativo local. Não é usada para acessar dados do navegador, histórico ou qualquer outra informação do usuário.

Compartilhamento de dados

Nenhum dado é compartilhado com terceiros, pois nenhum dado é coletado.
