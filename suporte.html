Pré-requisitos

  • Windows 10 64-bit ou superior
  • Token A3 ICP-Brasil (USB ou smartcard) com driver instalado
  • Host nativo Vero Signare — WebPKI instalado (VeroSignare-WebPKI.msi)
  • Google Chrome ou Microsoft Edge atualizado

Instalação

1
Baixe e execute o instalador VeroSignare-WebPKI.msi (requer permissão de administrador).
2
Reinicie o Chrome ou Edge após a instalação.
3
A extensão será instalada automaticamente pelo instalador. Verifique em chrome://extensions ou edge://extensions.
4
Conecte o token A3 e acesse a aplicação web para iniciar uma assinatura.

Problemas comuns

Extensão mostra "Host desconectado"
O host nativo não está instalado ou não foi encontrado. Reinstale o VeroSignare-WebPKI.msi como administrador e reinicie o navegador.

Token não detectado
Verifique se o driver do token está instalado corretamente e se o dispositivo aparece no Gerenciador de Dispositivos do Windows. Tente desconectar e reconectar o token.

PIN incorreto / token bloqueado
Consulte o fabricante do seu token A3 para procedimento de desbloqueio. O número de tentativas erradas permitidas varia por fabricante.

Extensão removida após atualização do navegador
Reinstale o VeroSignare-WebPKI.msi. O instalador reconfigura automaticamente a força de instalação da extensão via política do navegador.

Desinstalação

Acesse Configurações → Aplicativos → Aplicativos instalados, localize Vero Signare — WebPKI e clique em Desinstalar. A extensão e todas as configurações de registro serão removidas automaticamente.
